# Results Summary

The end‑to‑end MarketPulse prototype has been built and validated.

## Model Performance (reports/metrics.json)
- **Logistic Regression** – Accuracy ≈ 0.49, Precision ≈ 0.48, Recall ≈ 0.50.
- **Random Forest** – Accuracy ≈ 0.51, Precision ≈ 0.50, Recall ≈ 0.52.
- **LSTM** – Accuracy ≈ 0.50, Precision ≈ 0.49, Recall ≈ 0.51.
All models achieve ~50 % directional prediction, reflecting market efficiency and the limited feature set.

## Key Findings
- Technical indicators (MA, RSI, volatility) dominate predictive power; sentiment adds a small boost.
- Correlation‑based similarity graph clusters stocks by sector (e.g., IT, Financials).
- Streaming diagnostics (Bloom filter count, DGIM up‑tick counts, FM distinct ticker estimate) work in real‑time during the simulated stream.

## Limitations
- Simulated real‑time feed – not a live market connection.
- No order‑book or depth data; only OHLCV.
- Sentiment scoring falls back to VADER when Gemini API key is absent.
- Small dataset (NIFTY‑50) limits generalization.

## Outlook
- Integrate a real streaming source (e.g., WebSocket from a broker).
- Extend feature set with order‑book features and macro‑economic indicators.
- Experiment with more sophisticated deep‑learning architectures.
